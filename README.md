A one-letter diary entry for make.fun's **One Letter for Your Day** bounty.

The letter is **Z** — standing for **"zero sleep"**: an honest report of a
day spent building bounty entries through the night without sleep. One
letter, one word behind it, one very long night.

## Run it

```sh
node main.ts
```

The program writes exactly one character, `Z`, to `entry.txt` inside the
output directory (`MAKEFUN_OUTPUT_DIR` when set, otherwise `/output`).
Deterministic, no network, no files read outside this repository.
